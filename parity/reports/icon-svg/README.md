# Icon/SVG Parity Reports

This directory stores icon/SVG capture runs generated by:

- `npm --prefix client run parity:icons:capture`

Contract:

- Input target manifest: `parity/manifests/icon-svg-targets.json`
- Per-run artifacts: `parity/reports/icon-svg/<run-id>/`
- Latest pointer: `parity/reports/icon-svg/latest.json`

Each run writes:

- `results.json` with status per target and blockers (if any)
- `manifest.resolved.json` with resolved SVG hashes
- `report.md` markdown summary
- `shots/*.png` target screenshots
- `svgs/*.svg` extracted normalized SVG snapshots
